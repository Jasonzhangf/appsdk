# 本任务用户输入与范围

来源：本次 Codex 对话中的用户消息。下列内容按原文保存，供本任务 reviewer 对照。本文是对话输入的落盘转录，不能作为产品的可信身份认证或需求变更授权机制。

1. `检查我们现在是否有机制 lock 项目的真相不让更改？`
2. `用户可能需要输入一些需求，只能用户提出修改才能修改，否则永远作为真理存在`
3. `你画一个 dag 图，以及现在的 gap，落盘实现的文档，然后给我 goal 提示词`
4. `我认为权威要求是我们 reviewer 必须要校验的部分，所以需要加入 reviewer 的完整提示词要求中`
5. `这个应该是 appsdk 治理的一部分，不仅仅是我们现在使用的 reviewer 提示词，需要 agent 去根据要求把 reivew 模板加入我们的这部分真相`
6. `你现在要使用 gcm worker 进行编排执行`

本轮可交付增量为总设计 G9/T16：SDK 模板拥有与分发、公开 review 上下文组装、显式 reviewer 核验绑定、陈旧绑定拒绝及恢复。完整长期需求锁的 G1–G8/T1–T15 持续有效；本增量不等于全部完成，不为缺少可信授权降低其验收。

没有需求修改、撤销或降低验收的用户授权。现有目标确认字段和内容哈希不能证明真实用户身份。设计和产品输出须明确该边界。

当前用户未要求重启任何 daemon，未要求注册 Collab，也未要求创建 goal 订阅。GCM worker 使用新建 CLI 执行；实现和独立架构审查分离。完整实现目标、DAG、gap 和后续验收分别见 `docs/design/user-requirement-truth-lock.md` 与 `docs/goals/user-requirement-truth-lock-goal.md`。
