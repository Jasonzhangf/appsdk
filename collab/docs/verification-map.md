# Collab v1 verification map

| feature_id | positive gate | negative gate |
|---|---|---|
| identity.peer-register | first and later tmux panes register as equal peers; route persists full socket/server/session/pane identity | no inferred `master` from first register, implicit promotion, transfer, or Codex root treated as Collab master |
| identity.master-authority | approved self-promote only after pane liveness is explicitly absent; live master delegates to a present tmux peer; recovery preserves the original agent and master grant without promotion; journal replay preserves authority | live master, unknown/error liveness, ambiguous anchor, conflicting anchor, cross-project match, and init/register-as-master fail closed |
| task.self-lifecycle | one peer completes register→working→verifying→reviewed→delivered→accepted→merged→closed and cleanup; delivery/review/integration evidence survives journal replay; exact current `refs/heads/main` commit is required; legacy persisted `accepted` records without lifecycle evidence can record owner-local `merged` compatibility | current lifecycle records cannot bypass review/integration through direct status; legacy compatibility is limited to `accepted→merged`; non-owner review/integration is rejected; missing or mismatched main ref fails closed |
| task.scheduler-assignment | live master dispatches one assignment to an eligible ordinary peer, binds its direct-message lease, persists admission/task/message, owner accepts through `task accept`, and a two-peer replay preserves one assignment and its succeeded admission | failed or pending admission cannot enter managed `working`, cannot be consumed by `recv`, cannot trigger mailbox wake, and cannot be retried into a duplicate task/message; legacy `TaskDispatch`/`TaskClaim` remain fail-closed |
| task.worktree-cleanup | every worktree-bound task receives a durable cleanup receipt only after exact clean worktree/branch removal and absence verification | merged/closed/cancelled task with a bound worktree, missing receipt, mismatched receipt, existing path, dirty path, unmerged branch, or path escape fails closed |
| resource.p2p-conflict | conflict returns holder synchronously; subscribed exact release changes waiter to blocked and clears wait | no automatic holder/waiter message; no wake without matching subscription |
| wait.liveness | wait records waiter, blocker owner, deadline, resume, escalation and release | direct/two-peer/three-peer cycle, missing owner/deadline, terminal wait rejected; timeout creates no unsolicited message |
| notification.subscription | registration creates one deterministic seven-day default direct-message lease; a short explicit lease cannot suppress it; daemon replay restores it for a still-matching tmux binding; direct-message remains reusable until expiry; resource/deadline/async-result success consumes one-shot | unregistered/stale panes get no default lease; invalid event/TTL/subject/owner rejected; expired/cancelled/consumed registration cannot wake; one failed direct message cannot terminate the peer lease |
| notification.tmux-wake | durable mailbox/journal message → subscribed tmux pane paste-buffer → separate Enter; notification says `collab recv`; server returns `consumed=false` until a receive receipt exists; sender `MsgStatus` sees consumption from `ReceiveCommitted` | missing/unknown pane fails explicitly; paste or Enter failure is not accepted; input submission and pane output change never create a receive receipt; no AppServer fallback |
| notification.context | inbox/context/status return durable body and control projection | context does not consume or ACK notification; no unrelated peer supervision |
| daemon.tmux-route-resolution | exact tmux socket/server PID/session/pane/pane PID resolves through the current typed runtime binding; same session/pane on different sockets stays distinct; journal replay restores both routes; state and journal bytes remain unchanged | pane missing, liveness unknown/error, endpoint mismatch, zero/multiple matches, or stale tombstone fails explicitly and never falls back to cwd or legacy AppServer address; route lookup never returns an identity token |
| subagent.thread-operations | Start fails before creating a thread or mutating subagent state; Snapshot reports durable thread history unsupported; status uses pane observation; archive reports unsupported | no AppServer start/read/archive call; no fabricated history or snapshot receipt; no silent success |
| daemon.project-scope | `collab init` and lifecycle/config commands resolve the exact process cwd and do not consult any terminal session; normal thread-backed commands use the daemon route result; init merges `mcpServers.collab` and writes schema-valid Codex/Claude permission files | MCP/Agent path override absent; invalid path, ancestor capture, and sibling sharing fail closed; an uninitialized terminal cannot block init; existing non-collab MCP servers and unrelated project settings are preserved |
| integration.appsdk-live-closure | AppSDK promotion reads the persisted tmux endpoint, supplies `TMUX`/`TMUX_PANE` to `collab context` and `collab route resolve --tmux-session-id --pane-id`, and verifies the returned endpoint/scope/binding/generation; `rust/tests/cli_smoke.rs::lifecycle_chain_promotion_supports_parallel_first_create_and_reuse` | missing endpoint, mismatched endpoint, wrong pane/session arguments, stale generation, or unregistered identity cannot produce a live-closure record; AppServer/native-thread route flags are rejected |
| migration.peer-v1 | inspect→plan→apply→restart/rebind→verify preserves task/mailbox/journal and removes legacy declared roles | malformed/manual journal, second writer, changed snapshot, missing/inactive/unrelated wait holder fail closed |
| daemon.operator | controlled down→up uses installed binary and journal replay; exclusive `daemon.lock` flock prevents duplicate daemons and socket overwrite | mailbox text or peer role cannot authorize maintenance; duplicate daemon rejected |

Required integration gate: isolated tmux peers complete durable send → tmux wake
→ actual target `collab recv` → durable receive receipt → sender `MsgStatus`
proof, including explicit missing-pane and liveness-unknown failures.
