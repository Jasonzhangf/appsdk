# Architect 向 peer 直接派发执行任务

候选，待逐条批准。获授权 architect 可通过 task board 直接向同 scope 可承接的 peer 派发任务，无需由 master 代发；沿现有同名绑定、受邀确认和执行准入路径。
architect 完成规划与验收合同后需转交实现 → architect 提交任务 ID、当前 revision、目标 peer 与派发合同 → 派发后处于待接受，原归属保持；目标 peer 接受后转移执行归属；拒绝沿原流程。
