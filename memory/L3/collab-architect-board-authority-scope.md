# Architect 的 board 授权范围

候选，待逐条批准。当前已认证 architect 与获授权目标或任务分支建立有范围的 board 管理关系。architect 自设工作角色不构成自授写入权限。
architect 在其负责目标内组织实现 → 用当前名字和身份发起 board 写请求 → 合法范围内进入所请求操作；拒绝无 board 副作用。
