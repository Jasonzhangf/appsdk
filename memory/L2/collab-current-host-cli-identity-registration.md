# Collab 当前宿主 CLI 取证与 Rex/tmux 唯一身份绑定

Collab 用当前宿主环境的 CLI 获取身份锚定信息，先查询注册表，再更新身份绑定。Rex 按当前 block 唯一确认身份绑定。tmux 以 session 名字为唯一身份键，pane ID 为唯一呈现位置。已有 session 名字时按名字继承恢复项目逻辑名并更新 pane ID。缺 session 名字时，按当前 pane ID 查其绑定的旧 session，恢复名字并重命名当前 session。恢复或改名与用户要求冲突时，由用户裁决，裁决后只提交一个有效绑定。

Object：当前宿主 CLI 回执、项目注册表、项目逻辑名、Rex block、tmux session 名字与 pane ID。
Behavior：取证 → 查注册表 → 选择恢复路径 → 必要时待用户裁决或改名 → 唯一绑定。
Relation：Rex 当前 block 对应唯一当前绑定；tmux session 名字承载身份，当前 pane ID 承载呈现，缺 session 名字时用 pane 的既有旧 session 关系恢复名字。
