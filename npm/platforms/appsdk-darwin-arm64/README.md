# @jsonstudio/appsdk-darwin-arm64

macOS ARM64 runtime package metadata for AppSDK.

The M5 packaging flow assembles the verified `appsdk` and `project-memory`
macOS ARM64 binaries plus the three managed Skills into the paths declared by
`files` before this package is packed or installed. The tracked metadata does
not contain binary, Skill, or placeholder payloads.
