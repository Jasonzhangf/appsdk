# Collab v1 resource map

| resource_id | unique owner | truth store | allowed operations | forbidden relation |
|---|---|---|---|---|
| peer-identity | `identity::load_or_create` + Server registration | journaled `WorkerRec` + `RuntimeBinding.tmux_endpoint` | bind one peer to its current full tmux socket/server/session/pane endpoint; recover by one unique session/thread/pane anchor within project scope | inferred master from first register, copied token, claiming master from init/register, ambiguous or cross-project anchor |
| project-master-authority | live registered master peer through Server | journaled `Event::MasterAssigned` plus tmux pane liveness probe | user-approved self-promote only when no live master is proven; live-master delegate to a present tmux peer; identity recovery retains the same agent/grant | implicit first-register promotion, promote while a live master exists, recover on unknown/error, treating Codex root as Collab master |
| task-assignment | live master scheduler | journaled `SchedulerAdmissionRecord` plus `Sent`/`TaskRec` events | choose live idle registered peer before idle managed child; bind direct-message lease; persist one idempotent assignment by request ID | legacy `TaskDispatch`, automatic offer, duplicate reservation |
| task-lifecycle | assigned task owner peer | journaled `TaskRec` | accept assigned scheduler task, update, verify, integrate, close own task | another peer mutating lifecycle, accepting managed assignment through ordinary task entry |
| resource-claim | task owner peer through Server | active task feature/worktree claim | claim, hold, wait, release; conflict emits durable p2p notice | silent takeover, automatic release, global arbiter |
| wait-edge | waiter peer + blocking resource owner | `TaskRec.wait` | bounded wait, synchronous conflict result, deadline transition, subscribed release event | cycle, missing responsible peer/deadline/resume path |
| collaboration-journal | `server::Server` | `.agent-collab/server/journal.jsonl` | append/replay worker, task, message, migration events | manual JSON edits, silent replay skip |
| durable-mailbox | `server::Server` | `.agent-collab/mailbox/*.json` | persist required subject, original peer message, and subscribed event results | notification preview as truth, clearing during migration |
| notification-subscription | registered peer through Server | journaled `NotificationSubscription` + control-only tmux wake binding | registration creates/refreshed deterministic seven-day default direct-message lease; daemon replay restores it only for a still-matching registered tmux binding; query methods; register exact event/subject/TTL; status; unsubscribe; consume one-shot event subscriptions | unregistered or stale pane subscription, short explicit lease suppressing the default, payload-derived state, unbounded lease, another peer mutation |
| tmux-wake | `server` + `Event::WakeAttempted` + tmux adapter | journaled attempt ledger + transient id/subject/body preview; durable receive truth remains `ReceiveCommitted` | active subscription only; required abbreviated subject; safe one-line body preview; paste-buffer then independent Enter; prompt receiver to run `collab recv`; only receive receipt proves consumption; missing/unknown pane fails explicitly; no AppServer fallback | treating input submission or pane output as consumption; missing subject, notification burst, wake while unknown/working, automatic continuation, shell command injection, normal progress report |
| agent-context | `server::handle_context` | read-only Server state projection | peer identity, own tasks/waits, inbox, next actions | consuming notification, board management, other-peer supervision |
| tmux-route-resolution | `identity` + `server::ProjectRuntimeManager` | global identity current runtime binding plus matching typed project `runtime_binding` | read-only lookup by full tmux endpoint; return exactly one `RouteResolution`; historical routes excluded; zero matches `ROUTE_RESOLVE_NOT_FOUND`; multiple current matches `ROUTE_RESOLVE_AMBIGUOUS` | cwd, Git worktree, historical route, partial endpoint, or `routes.jsonl` selecting a route; token leakage; mutation during resolution |
| project-control-root | `scope::project_root_for_init` + `scope::lifecycle_project_root` + tmux-aware `Scope::resolve` | `collab init`/lifecycle: exact process cwd; peer commands: daemon route resolved from current tmux pane endpoint | initialize/control only the cwd project; resolve normal peer commands from TMUX endpoint | Agent/MCP path selection, Git or ancestor inference, sibling sharing, invalid path; uninitialized terminal cannot block init; lifecycle commands must not follow another pane binding |
| managed-subagent-thread-operations | `subagent` | durable subagent/task/mailbox journal state; no native thread archive truth | explicit unsupported Start and Snapshot; pane-only status; archive unsupported | AppServer thread creation/read/archive, fabricated snapshot receipt, silent success |
| daemon-maintenance | explicit local operator command | project socket/PID/events | install, controlled down/up, replay verification | deriving authority from peer role or mailbox text |
| migration-transaction | initiating authenticated peer + Server freeze | journaled `MigrationRecord` | inspect, plan, freeze, snapshot, restart, rebind, verify, resume | permanent master requirement, second writer, invented owner |

`/goal` delegation and interactive task recognition are outside this v1 milestone.
