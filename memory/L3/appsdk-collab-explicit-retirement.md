# Collab 明确退役释放普通名字并立即具备任务重派资格

来源为2026-11-12当前聊天01a1cf28-1d6f-7bc1-918e-186d04f98666。Jason对明确退役Bob的名字处理选择“释放 Bob，允许后续普通注册自动取得这个名字”（E1）。明确退役生效后解除当前名字持有，普通名字可再次分配；任务、消息、未交付资源保全沿既有规则。普通注册角色仍按R3默认peer，不能从释放Bob推导普通注册取得Jenny/master权限。

Jason随后选择“退役生效后立即具备重派资格，有合法 idle peer 就派发”（E2）。本分支不套用自动确认身份丢失后的15分钟回归等待。无合法idle时保留任务等待容量。邀请只表示邀请，按D1以新owner接受且daemon提交归属为真正派发完成，保持task ID、状态、证据与引用。T4.1/T4.2资源和迟到结果交接已批准，详见appsdk-collab-resource-late-result-handoff。明确退役的消息/通知/订阅具体处理尚待逐项确认。

Object为明确退役的稳定名字、当前holder和未完成任务。Behavior为授权退役、释放普通名字、即时重派资格和合法idle后的既有邀请/接受。Relation为名字-current、task-current assignment与可承接容量。owner为identity-map退役/名字分配、typed authority、task invite/accept/reclaim owner。E1/E2 approval=approved，执行edge/gate、黑盒及真实前端=pending。完整条款和正反例见task-runs/collab-identity-lifecycle-ontology-20261112/semantics.md，实际进展见同目录note.md。关联appsdk-collab-stable-name-lifecycle、appsdk-collab-task-offline-reclaim、appsdk-collab-role-inheritance与appsdk-collab-message-name-handoff。
