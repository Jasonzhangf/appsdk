# Rex block is the anchor

User-confirmed semantics on 2026-11-12: the Rex block entity itself is the anchor. A split creates a different block/anchor; resize, move and swap change layout placement but preserve the existing block identity. Window, layer and layout describe placement; Rex server/session locate and verify the block. Keep the block object definition separate from relations that assign current owners. An actual block has at most one current identity owner within the existing verified-server scope, and a later successful binding replaces that block's prior current owner while preserving the displaced persistent identity and business history. The project also has a separately approved stable-name relation requiring one current holder/anchor per assigned name, and an approved timed-detach behavior that releases execution/anchor; how those rules coexist with block replacement/detach is not resolved here. Do not infer automatic creation or reassignment of another block. This records semantics and design boundaries, not runtime or frontend acceptance.
